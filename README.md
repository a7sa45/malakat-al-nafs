# مَلَكة النفس

موقع عربي بسيط عن فهم المشاعر واختيار الاستجابة بدل الانصياع التلقائي للاندفاع.

الصفحة مكتوبة بـ HTML وCSS فقط، وتعمل مباشرة بفتح `index.html`. لا تحتاج إلى تثبيت مكتبات أو عملية بناء، وتدعم الجوال والقراءة من اليمين إلى اليسار والتنقل بلوحة المفاتيح.

## النشر

في Netlify: اربط المستودع، واترك أمر البناء فارغًا، واجعل مجلد النشر `.`.

في Vercel: اختر نوع المشروع `Other`، واترك أمر البناء فارغًا، واجعل مجلد الإخراج `.`.

## تعديل المحتوى

كل محتوى الموقع وتنسيقه داخل `index.html`. الأمثلة تعليمية عامة، ويمكن تعديلها بما يناسب السياق.
